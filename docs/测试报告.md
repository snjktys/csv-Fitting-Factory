| 类别 | 文件数量 | 覆盖内容 |

## 6. 已发现并修复的问题

| 问题 | 修复 |
|---|---|
| Matplotlib 默认字体不支持中文 | 自动选择 Microsoft YaHei、SimHei 等字体 |
| 数据点数量规则曾不统一 | 统一为总点数大于参数数，唯一 X 不少于参数数 |
| 指数可能溢出 | 给 `b` 设置与 X 尺度相关的边界，并捕获溢出 |
| 误差棒来源过于单一 | 增加无误差、CSV 列、统一误差三种模式 |
| 配置改变后可能误用旧结果 | 修改列、误差、模型、阶次或参数时让旧结果失效 |
