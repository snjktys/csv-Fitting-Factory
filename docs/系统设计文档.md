## 1. 设计目标与原则

### 1.1 设计目标

系统应允许没有 Python 编程经验的用户通过桌面图形界面完成以下工作：

1. 导入带表头的本地 CSV 文件；
2. 选择 X、Y，并选择误差模式（无误差、CSV 误差列或统一误差值）；
3. 对数据进行检查、转换和清理；
4. 使用多项式、指数、正弦或 Logistic 模型拟合；
5. 手动设置参数，或根据数据生成智能初值；
6. 查看原始数据、误差棒、拟合曲线和残差图；
7. 查看 R²、RMSE 和模型参数；
8. 将本次拟合结果导出为 TXT 报告。

### 1.2 设计原则

- **需求可追踪**：每个 Must Have 需求都有对应模块和验收条件。
- **界面与算法分离**：GUI 不直接实现 CSV 清洗、数学模型或评价指标。
- **单一职责**：文件读取、数据清理、拟合、绘图和报告分别封装。
- **明确失败**：异常转化为可理解的中文提示，不让程序直接退出。
- **原始数据只读**：系统不修改用户导入的 CSV 文件。
- **便于答辩**：核心公式、参数和调用流程保持清晰，避免不必要的框架和设计模式。
- **便于测试**：除 GUI 外的核心逻辑尽量设计为无界面的纯函数或服务函数。

### 1.3 项目边界

本系统是单机桌面工具，不包含用户登录、数据库、云端存储、在线共享和多人协作。

课程指导书在设计阶段通常要求数据库 ER 图；本项目只处理本地 CSV 文件，没有数据库实体关系，因此 **ER 图不适用**。本项目以“数据结构设计”和“模块数据流”替代 ER 图。

## 3. 总体架构设计

系统采用分层模块化结构：

1. **表示层**：接收用户操作并展示状态、数据和图形；
2. **应用协调层**：组织“加载—清理—拟合—绘图—导出”的调用顺序；
3. **业务计算层**：处理数据、数学模型、初值、拟合和评价指标；
4. **基础设施层**：负责 CSV 输入、TXT 输出和 Matplotlib 图形对象。

系统模块关系见 [系统模块图.svg](系统模块图.svg)。

### 3.1 建议代码结构

当前 `src/` 代码采用以下结构，各模块按职责协作：

```text
src/
├─ main.py                 # 程序入口
├─ app.py                  # 主窗口、事件协调和界面状态
├─ csv_handler.py          # CSV 编码尝试、读取和列信息
├─ data_processor.py       # 数值转换、清洗、排序和验证
├─ fitting_models.py       # 四种模型公式和参数元数据
├─ initial_guess.py        # 各模型智能初值
├─ fitting_engine.py       # curve_fit、残差和评价指标
├─ visualization.py        # 拟合图、残差图、误差棒
├─ report_generator.py     # TXT 报告内容与保存
└─ exceptions.py           # 业务异常类型
```

### 3.2 依赖方向

```text
main → app
app → csv_handler / data_processor / initial_guess / fitting_engine / visualization / report_generator
fitting_engine → data_processor / fitting_models
visualization → FitResult
report_generator → DatasetInfo / FitResult
```

底层模块不得反向引用 GUI，从而保证核心功能可以脱离界面进行单元测试。

## 4. 模块详细设计

### 4.1 GUI 界面模块

职责：

- 创建菜单、控制区、数据预览区、结果区、图形区和状态栏；
- 响应打开 CSV、列选择、模型选择、智能初值、开始拟合和导出报告事件；
- 根据应用状态启用或禁用按钮；
- 捕获业务异常并显示中文消息框；
- 将拟合结果交给可视化和报告模块。

GUI 不负责实现数学模型和数据清理规则。

### 4.2 文件处理模块

职责：

- 检查文件路径和扩展名；
- 按指定顺序尝试常见编码；
- 使用 Pandas 读取 CSV；
- 返回原始 `DataFrame`、文件名、编码、行列数和列名；
- 保留原始数据，不写回源文件。

编码尝试顺序：

1. `utf-8-sig`；
2. `utf-8`；
3. `gb18030`。

基础版本以逗号分隔 CSV 为主；若 Pandas 能可靠识别制表符或分号，可作为 Should Have 支持。

### 4.3 数据处理模块

职责：

- 验证 X、Y 不能选择同一列；
- 将选定列转换为数值；
- 将正负无穷转换为缺失值；
- 删除 X、Y 无效的数据行；
- 若选择“CSV 误差列”，同时删除误差值无效、为零或为负的行；
- 若选择“统一误差值”，校验该值为有限正数，并生成与 Y 等长的误差数组；
- 若选择“无误差”，不生成误差数组；
- 按 X 升序排列；
- 返回清洗后的 NumPy 数组和清洗统计信息。

处理规则：

- 不修改原始 `DataFrame`；
- 重复 X 默认保留；
- 清洗前后行数必须向用户展示；
- 预览最多展示前 100 行，计算使用全部有效数据；
- X、Y 必须为有限数值；
- 误差 `sigma`（若使用）必须全部为有限正数；
- 有效数据点总数必须 **大于** 模型参数数量；
- 唯一 X 数量必须 **不少于** 模型参数数量。

### 4.4 拟合模型模块

职责：

- 定义四种模型公式；
- 定义模型显示名称、参数名称、默认初值和参数数量；
- 统一模型查询接口；
- 对多项式创建指定阶次的动态函数。

模型公式见第 7 章。

### 4.5 智能初值模块

职责：

- 根据模型类型和清洗后的 X、Y 估计初始参数；
- 对无法可靠估计的情况返回安全默认值和警告；
- 不执行最终拟合；
- 将估计结果填入 GUI 参数输入框，允许用户修改。

### 4.6 拟合计算模块

职责：

- 校验参数数量和数据量；
- 调用 `scipy.optimize.curve_fit`；
- 在选择 CSV 误差列或统一误差值时传入 `sigma`；
- 生成预测值、残差、参数协方差和参数标准误差；
- 计算 R² 与 RMSE；
- 将底层异常转换为统一业务异常。

### 4.7 可视化模块

职责：

- 在 Matplotlib Figure 中维护两个纵向子图；
- 上图绘制原始散点、可选误差棒和拟合曲线；
- 下图绘制残差散点和 `y=0` 参考线；
- 设置标题、坐标轴、图例、网格和紧凑布局；
- 支持清空上一次结果。

### 4.8 报告生成模块

职责：

- 根据数据集信息、拟合配置和拟合结果生成文本；
- 通过保存对话框选择路径；
- 使用 `utf-8-sig` 编码写入 TXT，保证 Windows 中文兼容性；
- 发生保存失败时保留当前拟合结果并提示用户。

```text

  → 已选择有效数据列
  → 已准备参数
  → 正在拟合
```

- 正在拟合时禁用重复拟合按钮；
- Tkinter 控件只能由主线程更新。

## 7. 数学模型设计

### 7.1 多项式模型

公式：

```text
y = a0 + a1*x + a2*x² + ... + an*xⁿ
```

- 参数顺序固定为 `a0, a1, ..., an`；
- 阶次范围为 1～10；
- 参数数量为 `n + 1`；
- 有效数据点总数必须大于参数数量；
- 唯一 X 数量必须不少于参数数量；
- 选择 6～10 阶时显示“高阶多项式可能过拟合或产生振荡”的警告，但允许用户继续；
- 最终拟合调用 `curve_fit`，满足指导书要求；
- `numpy.polyfit` 仅用于智能初值，返回系数需转换为升幂顺序。

### 7.2 指数模型

公式：

```text
y = a * exp(b*x) + c
```

参数：

- `a`：指数项幅值；
- `b`：增长或衰减速率；
- `c`：纵向偏移。

指数模型不得通过静默裁剪 `b*x` 来掩盖溢出，因为裁剪会改变实际模型。设计采用以下策略：

1. 根据 X 的数值尺度为参数 `b` 设置集中管理的有限边界；默认使 `|b*x|` 保持在安全计算范围内；
2. 校验初值 `b0` 是否在边界内，超出时提示用户调整初值或缩放 X；
3. 使用 NumPy 浮点错误检测捕获指数溢出和非法数值；
4. 发生溢出时中止本次拟合，并提示“调整初值或缩放 X 数据”，不返回被裁剪的伪结果。

编码阶段建议以 `max_abs_x = max(abs(x))` 为尺度，并使用集中配置的 `b_limit`（例如 `100 / max(max_abs_x, epsilon)`）作为默认对称边界。该数值必须通过示例数据和边界测试验证，不得散落在 GUI 代码中。

### 7.3 正弦模型

公式：

```text
y = A * sin(2π*f*x + phi) + c
```

参数：

- `A`：振幅；
- `f`：频率；
- `phi`：相位；
- `c`：纵向偏移。

基础版本只拟合单一正弦。指导书中的多正弦叠加和 FFT 主频扩展属于进阶功能，不进入当前 Must Have 范围；但单正弦智能初值允许使用 FFT 估计主频。

### 7.4 Logistic 模型

公式：

```text
y = c + L / (1 + exp(-k*(x - x0)))
```

参数：

- `L`：上下平台差值，设计约束为正数；
- `k`：增长速率，可正可负，负数表示下降型曲线；
- `x0`：曲线中点；
- `c`：下平台基线。

采用四参数 Logistic，以覆盖存在非零基线的实验数据。

## 8. 智能初值算法设计

智能初值只提供合理起点，不保证拟合一定成功。计算结果显示在界面中，用户可以修改。

### 8.1 多项式初值

1. 检查阶次和数据量；
2. 使用 `numpy.polyfit(x, y, degree)` 粗略估计；
3. 将 NumPy 的降幂系数转换为 `a0...an` 升幂顺序；
4. 若矩阵病态，提示用户降低阶次或调整 X 范围。

### 8.2 指数初值

1. `c0 = min(y)`；
2. 令 `shifted = y - c0 + epsilon`；
3. 对 `log(shifted)` 与 X 做一次线性拟合，斜率作为 `b0`；
4. 截距的指数作为 `a0`；
5. 若对数估计不可用，使用 `a0 = max(y)-min(y)`、`b0 = 1/x_range`、`c0 = min(y)`。

### 8.3 正弦初值

1. `c0 = mean(y)`；
2. `A0 = (max(y)-min(y))/2`；
3. 将数据按 X 排序；
4. 若 X 间隔近似均匀，对去均值后的 Y 做 FFT；
5. 忽略零频，取最大幅值频率作为 `f0`；
6. `phi0` 初始设为 0；
7. 若 X 间隔明显不均匀，则使用 `f0 = 1/x_range` 并给出警告。

### 8.4 Logistic 初值

1. `c0 = min(y)`；
2. `L0 = max(y)-min(y)`；
3. 计算中间水平 `c0 + L0/2`；
4. 取最接近中间水平的数据点 X 作为 `x0`；
5. 根据 X 与 Y 的相关方向设置 `k0` 正负号；
6. `abs(k0)` 初始取 `4/x_range`；
7. 若 Y 范围接近零，拒绝 Logistic 拟合并提示数据变化不足。

## 9. 拟合计算设计

完整算法流程见 [拟合算法流程图.svg](拟合算法流程图.svg)。

### 9.1 curve_fit 调用策略

基础调用参数：

```text
curve_fit(
    model_function,
    x,
    y,
    p0=initial_params,
    sigma=sigma_or_none,
    absolute_sigma=error_mode_is_not_none,
    maxfev=20000,
)
```

设计约束：

- 参数框内容必须全部成功转换为有限浮点数；
- 参数数量必须与模型完全一致；
- 误差模式为 CSV 误差列或统一误差值时，`sigma` 必须全部为有限正数；
- 多项式可按阶次动态创建函数；
- 多项式有效点总数必须大于参数数量，唯一 X 数量必须不少于参数数量；
- 多项式为 6～10 阶时先显示风险警告；
- 指数模型对 `b` 使用数据尺度相关的有限边界，并捕获溢出，不静默裁剪模型输出；
- Logistic 对 `L` 施加正值边界；
- 正弦频率 `f` 施加正值边界；
- 对模型特有边界的具体数值在编码阶段通过集中元数据定义，不能散落在 GUI 中。

### 9.2 残差

残差定义为：

```text
residual_i = observed_y_i - predicted_y_i
```

残差图以 X 为横轴、残差为纵轴，并绘制 `y=0` 参考线。

### 9.3 R²

```text
SSE = Σ(y_i - predicted_y_i)²
SST = Σ(y_i - mean(y))²
R² = 1 - SSE/SST
```

若 `SST = 0`，说明所有 Y 相同，R² 无定义。此时显示 `N/A`，不能伪造为 0 或 1。

### 9.4 RMSE

```text
RMSE = sqrt(mean((y_i - predicted_y_i)²))
```

RMSE 与 Y 使用相同单位。

### 9.5 参数不确定度

虽然需求只强制输出参数、R² 和 RMSE，但 `curve_fit` 会返回协方差矩阵。系统应在可估计时计算：

```text
parameter_error = sqrt(diag(covariance))
```

参数标准误差作为 Should Have 展示并写入报告；协方差不可估计时不阻止展示拟合曲线，但需显示警告。

## 10. 可视化设计

### 10.1 拟合结果图

- 原始数据：蓝色散点；
- 误差棒：误差模式为 CSV 误差列或统一误差值时绘制；选择“无误差”时不绘制；
- 拟合曲线：红色实线；
- 为保证曲线平滑，使用 X 范围内 500 个等距点计算绘图曲线；
- 图例至少包含“原始数据”和模型名称；
- 标题显示模型名称；
- 坐标轴名称使用用户选择的列名。

### 10.2 残差图

- 残差点：紫色或橙色散点；
- 零线：黑色虚线；
- 横轴沿用 X 列名；
- 纵轴名称为“残差”；
- 残差图不自动隐藏异常点。

### 10.3 空状态

程序启动或结果失效时，图形区显示两个空坐标轴和操作提示，不显示上一次无效结果。

## 12. 异常处理设计

建议定义统一的业务异常基类 `FittingFactoryError`，GUI 只处理业务异常和兜底异常。

| 异常场景 | 处理策略 | 用户提示重点 |
|---|---|---|
| 用户取消文件对话框 | 不报错，保持当前状态 | 无 |
| 文件不存在或无权限 | 中止读取 | 检查路径和权限 |
| 编码均失败 | 中止读取 | 建议另存为 UTF-8 CSV |
| CSV 为空 | 中止加载 | 文件没有可用数据 |
| 列数不足 | 中止加载 | 至少需要两列 |
| X、Y 相同 | 禁止拟合 | 重新选择不同列 |
| 非数值或缺失值 | 删除无效行并提示数量 | 显示清理统计 |
| 清理后数据为空 | 禁止拟合 | 更换列或修正数据 |
| 有效点总数不大于参数数 | 禁止拟合 | 增加数据或降低阶次 |
| 唯一 X 少于参数数 | 禁止拟合 | 增加不同 X 或降低阶次 |
| 选择 6～10 阶多项式 | 允许继续但先警告 | 高阶模型可能过拟合或振荡 |
| CSV 误差值小于等于零 | 删除对应行并提示 | 误差必须为正数 |
| 统一误差为空、非数字或小于等于零 | 禁止拟合 | 输入有限正数 |
| 参数为空或非数字 | 禁止拟合 | 指出具体参数名 |
| 模型计算溢出 | 中止拟合 | 调整初值或数据尺度 |
| `curve_fit` 不收敛 | 保留数据、不生成结果 | 使用智能初值或修改参数 |
| 协方差不可估计 | 允许展示结果并警告 | 参数不确定度不可靠 |
| R² 无定义 | 显示 `N/A` | Y 数据没有变化 |
| 报告保存失败 | 保留拟合结果 | 更换保存位置 |

所有异常都不得导致主窗口退出。

## 13. 性能与可维护性设计

### 13.1 数据规模

- 类使用帕斯卡命名法；

- 如课程要求说明工具使用，已在项目文档中按实际过程记录；本人已确认代码注释只保留有助于理解逻辑的内容；
