## 2. Bug 修复记录

### 测试脚本兼容性问题：Pandas 3 禁止向 float64 列写入字符串

- 现象：随机测试准备“缺失”字符串时，Pandas 直接抛出类型错误；
- 原因：Pandas 3 对隐式类型升级更严格，float64 列不能直接混入字符串；
- 修复：在测试数据构造阶段先将该列转换为 `object`，再写入异常字符串；
- 结果：测试成功覆盖真实的非数字清洗场景，业务代码无需修改。

### Bug 1：中文图表字体缺失

- 现象：Matplotlib 测试出现大量中文字形缺失警告；
- 原因：默认 DejaVu Sans 不包含完整中文；
- 修复：按优先级选择 Microsoft YaHei、SimHei、Noto Sans CJK SC；
- 结果：测试重新通过且无字体警告。

### Bug 2：数据点规则存在歧义

- 现象：设计文档中“总点数”和“唯一 X”条件表述不同；
- 修复：总点数必须大于参数数，唯一 X 必须不少于参数数；
- 结果：规则已写入设计、代码和测试。

### Bug 3：指数模型可能产生伪结果

- 现象：如果直接裁剪指数输入，虽然不溢出，却改变了数学模型；
- 修复：不静默裁剪；根据 X 尺度限制 `b`，溢出时明确失败；
- 结果：模型含义保持正确。

### Bug 4：旧拟合结果与新配置不一致

- 现象：用户修改列或参数后，旧报告可能不再对应当前设置；
- 修复：任何配置变化都会清空图形、指标和报告状态；
- 结果：只能导出最新成功拟合的结果。

### Bug 5：参数符号缺少公式对应关系（学生人工发现，AI 协助修正，2026-09-12）

- 发现过程：学生查看参数设置界面截图时发现，输入框只有 `a0`、`a1`、`a`、`b` 等字母数字，未标注这些符号在模型公式中的具体含义，手动设置初值时容易误解。
- 原因分析：`ModelSpec` 仅保存参数名，没有保存参数说明；GUI 只渲染参数名，没有展示模型公式。
- 修复内容：
  - 为 `ModelSpec` 增加 `parameter_descriptions` 字段，并为四种模型建立与参数顺序一致的中文说明；
  - 在 GUI 参数区域增加公式显示；
  - 将参数标签改为“符号（含义）”，例如 `a1（x^1 项的系数）`、`k（增长/下降速率）`；
  - 增加模型元数据测试，确认说明数量和顺序与公式一致。
- 人工复核：重点检查多项式升幂系数顺序、指数模型 `a/b/c`、正弦模型 `A/f/phi/c` 以及 Logistic 模型 `L/k/x0/c` 的对应关系。
- 修复结果：用户在设置初值时可以直接看到公式和参数含义，原有拟合函数参数顺序不变，不影响计算逻辑。
- 验证状态：源码编译和核心元数据检查通过；完整自动化测试需由学生本人在安装 pytest 的环境中运行并记录结果。

### Bug 6：按钮样式不一致及小窗口底部状态栏消失（学生人工发现，AI 协助修正，2026-09-12）

- 发现过程：实际启动 GUI 后发现“智能初值”使用 ttk 默认按钮样式，而“开始拟合”使用强调样式，字体大小和按钮高度不一致；切换到较小窗口并选择高阶多项式时，参数行增多会使最下面的状态栏消失。
- 原因分析：两个按钮的 style 不统一；左侧控制区没有滚动机制；`main` 主区域先使用 `pack(fill=BOTH, expand=True)`，状态栏最后 pack，导致状态栏被主区域抢占空间。
- 修复内容：
  - 新增 `Action.TButton`，统一“智能初值”和“开始拟合”的字体（Microsoft YaHei UI 10 bold）及内边距；
  - 左侧控制区改为 Canvas + Scrollbar，内容超出可视高度时可滚动；
  - 状态栏改为先 pack，主内容区随后 expand，确保状态栏始终保留固定高度；
  - 多项式参数区改为按内容自然增长，不再强行占满剩余高度。
- 人工复核：在 1050×680 和 1050×400 窗口尺寸下生成 10 阶多项式参数，确认底部状态栏仍显示，左侧滚动区域的 scrollregion 有效；确认两个按钮使用相同 style。
- 修复结果：小窗口下状态栏不再消失，参数过多时可以滚动查看；按钮视觉尺寸统一，操作区更易识别。
- 验证状态：实际启动 GUI 冒烟检查通过；Tk 几何检查确认状态栏高度为 33px、10 阶参数滚动区域有效；全部 47 项自动化测试通过。

### Bug 7：左侧滚轮误改下拉框选项且滚动不稳定（学生人工发现，AI 协助修正，2026-09-12）

- 发现过程：学生实际使用鼠标滚轮时发现，指针在输入量、输出量或误差来源下拉框上方时，滚轮会改变选项；滚动左侧整体区域时又存在时灵时不灵的情况。
- 原因分析：旧代码通过 `bind_all` 绑定滚轮，无法可靠阻止 ttk Combobox/Spinbox 的默认事件处理；滚轮绑定只在部分容器进入/离开时切换，子控件之间传播不一致。
- 修复内容：
  - 为左侧控制区增加专用 bind tag，并递归安装到所有控件的 bindtags 首位；
  - 统一处理 `<MouseWheel>`、`<Button-4>` 和 `<Button-5>` 事件；
  - 滚动左侧 Canvas 后返回 `break`，阻止 Combobox/Spinbox 改变当前值；
  - 动态生成的多项式参数输入框在创建后重新安装滚轮绑定。
- 人工复核：向 X 列 Combobox 发送滚轮事件，确认选项仍为原值；确认左侧 Canvas 的滚动位置发生变化；确认右侧图表区域不使用左侧滚轮绑定。
- 修复结果：滚轮只负责滚动左侧控制区，不再意外修改下拉框或数字框参数，左侧各控件位置的滚动行为统一。
- 验证状态：Tk 事件级检查通过；完整 47 项自动化测试通过。学生提交前需在实际鼠标设备上复测滚轮上下滚动。

### Bug 8：全屏时仍保留无效滚轮操作（学生人工发现，AI 协助修正，2026-09-12）

- 发现过程：学生进一步实际操作发现，全屏时左侧参数内容已经全部可见，但滚动容器仍持续接收滚轮，使用体验不够自然。
- 原因分析：旧实现无论内容是否超出视口都显示滚动容器，没有按窗口大小动态判断滚动需求。
- 修复内容：
  - 根据 Canvas `scrollregion` 内容高度和当前视口高度计算 `_controls_scrollable`；
  - 内容完全可见时隐藏滚动条、回到顶部并忽略滚轮；
  - 内容超出视口时显示滚动条并启用滚轮；
  - 窗口大小变化、模型切换和参数行重建后重新计算滚动状态。
- 人工复核：1050×800 + 2 阶多项式时滚动条隐藏且 `yview` 不变；1050×680 + 10 阶多项式时滚动条显示并可滚动；切换回低阶模型后滚动条重新隐藏。
- 修复结果：全屏或大窗口无需滚轮，小窗口和高阶参数仍有明确、可用的滚动能力。
- 验证状态：Tk 几何/事件检查通过；完整 47 项自动化测试通过。

### Bug 9：Matplotlib 工具栏提示为英文（学生人工发现，AI 协助修正，2026-09-12）

- 发现过程：学生实际查看图表工具栏时发现，鼠标悬停平移按钮会显示 `Left button pans, Right button zooms` 等英文提示，与程序其他中文界面不一致。
- 原因分析：Matplotlib `NavigationToolbar2Tk` 默认 `toolitems` 使用英文 Tooltip；项目直接实例化默认类，未提供中文本地化文本。
- 修复内容：
  - 在 `src/app.py` 新增 `ChineseNavigationToolbar2Tk` 子类；
  - 覆盖 Home、Back、Forward、Pan、Zoom、Subplots、Save 的 Tooltip 文本为中文；
  - 保留 Matplotlib 原有图标、按钮回调、平移/缩放/保存功能，不改第三方库源码。
- 人工复核：确认平移提示包含左键拖动、右键缩放、X/Y 固定坐标轴和 Ctrl 固定纵横比；确认缩放、子图配置和保存提示均为中文。
- 修复结果：图表工具栏的悬停说明与主界面语言统一，用户无需阅读英文即可理解操作。
- 验证状态：实际 GUI 创建检查通过，工具栏类为 `ChineseNavigationToolbar2Tk` 且 7 个工具项均有中文提示；完整 47 项自动化测试通过。

### Bug 10：子图配置窗口内部仍为英文（学生人工发现，AI 协助修正，2026-09-12）

- 发现过程：学生点击已中文化的“配置子图”按钮后，发现新窗口内部的标题、操作说明、边距/间距滑块和 `Reset` 按钮仍显示英文。
- 原因分析：Matplotlib `SubplotTool` 直接创建英文标签，并通过滑块标签文字拼装 `subplots_adjust` 参数；简单替换文字会把 `left` 等合法参数变成中文而导致功能错误。
- 修复内容：
  - 新增 `ChineseSubplotTool` 子类，中文化窗口说明、六个滑块和重置按钮；
  - 在 `ChineseNavigationToolbar2Tk.configure_subplots` 中创建中文配置窗口；
  - 重写滑块变化处理，使用固定的 `left/bottom/right/top/wspace/hspace` 内部键，不依赖中文显示标签；
  - 新增测试，检查工具栏提示和子图参数中文标签。
- 人工复核：打开配置窗口读取所有文字；移动左边距滑块，确认目标 Figure 的 `subplotpars.left` 改变，证明中文化后功能仍有效。
- 修复结果：配置子图窗口的用户可见文字全部中文化，滑块调节和重置功能保持原有逻辑。
- 验证状态：配置窗口实际创建和滑块操作检查通过；完整 48 项自动化测试通过。
